# 📝 Text Classification using Naive Bayes

This project demonstrates **text classification** using `CountVectorizer` for feature extraction and **Multinomial Naive Bayes** for classification.

## 🚀 Features
- Load and preprocess text dataset
- Convert text into numerical form using Bag of Words (CountVectorizer)
- Train Naive Bayes classifier
- Evaluate model with:
  - Accuracy
  - Precision, Recall, F1-score
  - Confusion Matrix (visualized with Seaborn)
- Predict sentiment/class for new input text

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- scikit-learn
- Matplotlib, Seaborn
